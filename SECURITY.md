# Security policy

Report sensitive findings through
[GitHub private vulnerability reporting](https://github.com/bolens/agent-skills/security/advisories/new)
after the repository is published, or use the contact address on the
[maintainer profile](https://github.com/bolens).

Skills can execute commands, read repositories, and call tools. Reports should
identify the affected skill, exact revision, trigger, permissions involved,
and whether the behavior can expose secrets or mutate external state.

Upstream vulnerabilities should also be reported to the original project linked
from the affected skill's `UPSTREAM.md`.
