# Individual legacy skill contracts

Retrospective at `c0bfd04`, inspected 2026-09-06. These 62 entries expand the
original domain contracts with each packaged skill's observable procedure and
an acceptance scenario. They describe source-guided workflows. They are not
claims that every external application, host or browser was exercised.

Each skill owns its linked references and platform limits. Repository helpers
and packaged executables have separate contracts and runtime evidence. Original
features 001–005, 007 and 008 retain authority within their scopes. FR-009–010
in [spec.md](spec.md) identify corrections discovered during this extension.

## Maintenance and delivery

A failed status query is unknown, never a clean repository. Publication and operational actions retain separate authority. Optional local structural analysis retains [original 009](../009-sentrux-local-analysis/spec.md), including verified runtime/scope and unavailable evidence. |

| [ci-maintenance](../../skills/ci-maintenance/SKILL.md) | Resolve repository policy, host settings, exact shared callers and current platform documentation before changing gates. Verify event trust, status propagation, permissions, concurrency, pin monitoring and representative callers. A skipped security job is not an executed audit. |

| [setup-pre-commit](../../skills/setup-pre-commit/SKILL.md) | Reuse native tools and staged-file ownership, keep expensive gates separate, and test real staged behavior. | [resolving-merge-conflicts](../../skills/resolving-merge-conflicts/SKILL.md) | Inspect the owned operation, index stages and both source intents, resolve only related conflicts, then validate before continuing. Removing markers alone is insufficient. No implicit abort, reset or history rewrite is permitted. |
| [changelog-maintainer](../../skills/changelog-maintainer/SKILL.md) | Preserve release and migration facts while converting history into reader-visible outcomes. Fix generators before generated prose. A routine dependency bump stays in history unless it changes compatibility, security or operation; no invented release date or version. |
| [find-skills](../../skills/find-skills/SKILL.md) | Compare an actual missing task with installed, discoverable and observed-used capabilities; inspect candidate source, license and behavior. Low usage alone does not justify pruning a recovery skill. Discovery does not install or transfer private context. |
| [sync-skill-upstreams](../../skills/sync-skill-upstreams/SKILL.md) | Compare exact audited tips, review upstream and fork diffs, preserve local changes/licenses and regenerate provenance after an authorized import. A changed branch tip is only a candidate; the scheduled audit never imports or merges it. |
| [release-packaging](../../skills/release-packaging/SKILL.md) | Apply [008](../008-release-packaging/spec.md): assess nine default ecosystems plus conditional additional targets, map source/binary/main variants natively, and verify clean installs, ABI, dependency closure and immutable identity. A Windows-capable compiler does not prove the application supports Windows. |

| [systematic-debugging](../../skills/systematic-debugging/SKILL.md) | Capture and reproduce the exact failure, trace inputs and original process status, test one falsifiable hypothesis, then make an authorized scoped fix.
