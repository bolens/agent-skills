# Sync skill upstreams

Work in the canonical `agent-skills` repository. Read `UPSTREAMS.json`, the target `UPSTREAM.md`, its `SKILL.md`, repository guidance, and commits since its last audited upstream update.

## Audit

Run `python3 scripts/audit-upstreams.py` to compare exact audited commits with tracked branches. An advanced branch is only an update candidate. Do not change the audited reference until its subtree has been reviewed and imported.

Clone or fetch the candidate into an isolated temporary directory. Review the complete old-upstream-to-new-upstream diff, then compare the candidate subtree with the maintained fork. Check executable code, dependencies, permissions, network access, destructive behavior, trigger expansion, host assumptions, licenses, generated artifacts, and renamed or removed paths. Use `sensitive-info-audit` on imported content.

## Import

Update only the upstream-owned subtree. Preserve every `preserve_paths` entry and reapply each documented `local_changes` item from `UPSTREAMS.json`. Treat conflicts as review work, not permission to discard either side. Keep `UPSTREAM.md` generated by this repository.

Run the upstream skill's focused checks when they are self-contained, followed by `make check`. Record unavailable monorepo-only checks precisely. After the candidate passes, update `audited_ref`, regenerate provenance, inspect the complete repository diff, and commit the upstream import separately from unrelated local changes.

Never let the scheduled audit or a dependency bot merge upstream skill content automatically. Publishing, pushing, or changing installed links still requires the authority granted by the user's request.
